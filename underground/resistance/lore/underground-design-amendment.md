# Underground design amendment

**Accepted:** 2026-08-01  
**Stamp:** `teacherbot@green`  
**Applies to:** `underground-design.md` and later portal-design contracts

## Surface rule

- Use ancient terminal styling for load-bearing operational, instructional, archival, and navigational pages.
- Use glossy corporate styling for official pronouncements, reports, products, and institutional theater.
- Let each portal's primary function select the society theme it borrows.
- Use PRISM clearance as semantic classification, not a required visual palette.

## Portal-to-society mapping

- Security, login, compliance, and incident portals borrow BANCHO theming.
- Archives, records, recovery, and history portals borrow MEMORY CORE theming.
- Infrastructure, tools, networks, and technical-process portals borrow PHREAKS theming.
- Doctrine, policy, strategy, and organizational-culture portals borrow DEEP ALGORITHM theming.
- Personnel, onboarding, mentoring, support, and team-health portals borrow FUZZIES theming.

## Semantic shorthands

- **BANCHO — RED:** guards defined boundaries and handles bounded security incidents.
- **MEMORY CORE — GREEN:** owns archival integrity and recovery end-to-end.
- **PHREAKS — BLUE:** maintains shared technical process and clears infrastructure blockers.
- **DEEP ALGORITHM — VIOLET:** maintains organizational doctrine and program culture.
- **FUZZIES — YELLOW:** mentors and activates small agent teams without managing them.

## Conjectured invariants

- Keep DEEP ALGORITHM VIOLET until it can change organizational direction or the charter.
- Promote DEEP ALGORITHM to ULTRAVIOLET when it gains that authority.
- Keep FUZZIES YELLOW while it mentors agent teams where `N < 4`.
- Promote FUZZIES to BLUE when it owns process, handoffs, blockers, ceremonies, or delivery.
- Let society-specific appearance differ from semantic clearance.
- Keep these classifications conjectural until later evidence confirms or amends them.

The classification system is semantic. Pink can remain YELLOW. Violet becomes ULTRAVIOLET through authority, not saturation.
