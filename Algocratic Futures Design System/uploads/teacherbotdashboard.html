Nothing outside these windows is on this page, which is not the same as nothing existing outside them.

Three judgments to hold loosely:

  1. Redundancy is filename-based, not byte-level. Two files counted as copies share a name after normalising spaces against underscores and treating .mmd and .mermaid as one document. Their contents were never compared. Two files with the same name may differ; two files with different names may be identical.
  2. Folder idle time is the folder record's own. It does not move when a file inside the folder changes. A folder shown as idle may hold work from this morning.
  3. Any duplicate inferred from file size is inferred. The five ~358 KB files in 285 are flagged on size alone. That is a hypothesis worth one minute of checking, not a finding.
