02The sharpest opening

SEATS.md assigns four model seats and then flags every one of them “priors, unprobed.” It also says: this file is data; it reopens on every model release and on every probe battery run. That is a half-life, written by someone else, waiting for a machine that runs on a schedule.

SEATS.md ASSIGNSAuditor — Fable 5. “ASSAY protocol only. Strongest model spends tokens on spot re-derivation and drift audit, not the hot loop.”
THE ESTATE BUILTAuditor — Friday 02:00. Six checks, read-only, drift and re-derivation, deliberately off the nightly hot loop. Same name. Same job. Arrived at separately.

There is a probe_battery_v0.md in the repository and nothing that runs it on a cadence. The estate is the only thing in either system that wakes up on its own. That is the leverage: the estate can turn the seat map from priors into measurements.

03Four moves

Ordered by dependency. The first is cheap and unblocks the language; the second is the unique contribution; the third pays off an open contradiction; the fourth reaches 26FA.

MOVE 01 · this week

Adopt one vocabulary

Stop maintaining two dialects of the same discipline. The estate speaks Algorithm.

  • Map the clerk gate onto the floor test — keep both names only where they mean genuinely different things
  • Lock chantry reports to STE: ≤20 words per line, active imperative, no idioms
  • Chantry posts are field reports. The repository already has bridge/ for exactly that — route them there
  • Adopt the fixed strings verbatim as checksums, including the failure string
Owner: Neo  ·  Cost: one editing pass over six prompts
MOVE 02 · the real prize

Probe the seats

Turn SEATS.md from priors into evidence. Nothing else in the estate does something the Algorithm cannot already do alone.

  • The Friday Auditor runs probe_battery_v0 against each seat assignment
  • Results land as dated run files — append-only, per the amendment discipline
  • A seat whose behavior contradicts its prior is a contradiction entry, not a silent edit
  • Re-runs on every model release, which is what the file already asks for
Owner: Auditor  ·  Blocked on: reading the probe battery; the Almanac fault first
MOVE 03 · pays a debt

Floor-test the intake

A quarter of Drive root would not classify. I called that a taxonomy gap. The floor test suggests a better diagnosis.

  • The Archivist adds the floor test to every intake artifact: Audience · Scope · Format · Path
  • An artifact that cannot state all four is below floor — flagged, not filed
  • “Unclassifiable” splits into outside the taxonomy versus never finished — different problems, different fixes
  • ASSAY the estate's own documents; a plan that cannot survive its own floor is padding
Owner: Archivist  ·  Closes: the 26-file unclassified list
MOVE 04 · reaches 26FA

Teach the gate

PRISM already grades capability by band. The Algorithm is a competency that grades the same way — and Module Zero recurs in every course.

  • Bind Algorithm competencies to PRISM bands (below)
  • Module Zero + banks the evidence: a frozen contract, a cut log, an assay
  • CTS 285 sits at ORANGE, CSC 289 at GREEN — both are 26FA-adjacent and both have live templates
  • Angela authored PRISM. The binding is a conversation with her, not a decision to announce
Owner: the human seat  ·  Window: classes open 2026-08-17
